
Fedora Support for Mac-Intel 2013-2017

A lightweight, automated community remix designed to bring a seamless, out-of-the-box Fedora Linux experience to Intel-based Apple Macintosh computers manufactured between 2013 and 2017.

About the Project

This is a non-commercial, community-driven personal project. We are not seeking fame, profit, or commercial recognition. Our sole mission is to make Fedora Linux genuinely accessible and functional for older Intel Macs, extending the lifespan of these beautifully engineered machines with modern, open-source software.
By leveraging automated cloud build workflows, this repository generates installable Fedora ISO images that include necessary hardware enablement tools natively. This eliminates the hurdle of troubleshooting uncooperative hardware configurations entirely offline.
